# sites-hub

Control center for static websites on GitHub Pages. Everything lives in GitHub: no backend, no other clouds.

- Hub home page: https://msather.github.io/sites-hub/
- Registry: [sites.md](sites.md)
- Agent instructions: [CLAUDE.md](CLAUDE.md)
- Architecture: [docs/architecture.md](docs/architecture.md)

To create a site: **Actions → Create site → Run workflow**, or ask an agent.
